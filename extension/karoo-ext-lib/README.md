# karoo-ext (Hammerhead's extension library), copied in

`src/` is the `lib/src` folder of https://github.com/hammerheadnav/karoo-ext at commit f79f103
(18.8.2026, library version 1.1.9), unchanged. Licence: Apache 2.0, see `LICENSE`.

Hammerhead publishes the built library on GitHub Packages, which wants a GitHub login even for
public packages. Building it from its source here needs no account.
